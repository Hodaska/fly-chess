# Муха играет в шахматы 🪰♟

Настоящий мозг самца дрозофилы (коннектом **MaleCNS v1.0**, 126 414 нейронов, 4,48 млн связей)
смотрит на доску и выбирает ход. Обучен только последний линейный слой (копирование ходов Stockfish),
граф мозга не менялся. Уровень начинающего, зато мозг настоящий. 3D-сцена: муха физически
носит фигуры, справа — живая активность мозга.

## Как запустить (одна команда)

Нужен только **Python 3.10+** (лучше 3.12 или 3.13): https://www.python.org/downloads/
(при установке на Windows поставьте галочку «Add python.exe to PATH»).

```bash
git clone https://github.com/Hodaska/fly-chess.git
cd fly-chess
python play.py
```

Всё остальное сделает скрипт: создаст окружение, поставит зависимости, скачает данные мозга
(~570 МБ) и Stockfish, запустит игру и откроет браузер на http://127.0.0.1:8000.
Первый запуск 5-15 минут (нужен интернет, ~2,5 ГБ свободного места), следующие — секунды.
Остановить: `Ctrl+C` в окне терминала.

Видеокарта не нужна: на обычном процессоре мозг думает ~1 секунду за ход (нужно ~2 ГБ ОЗУ).
Если Python называется `python3` (Linux/macOS), запускайте `python3 play.py`.

## Режимы

«я против мухи», «я против Stockfish», «муха против Stockfish» (+ сила Stockfish).
Ходить: клик по своей фигуре, затем по клетке; тянуть мышью — вращать камеру, колесо — приближение.
Stockfish скачивается автоматически на Windows; на Linux/macOS: `sudo apt install stockfish` / `brew install stockfish`
(режим «я против мухи» работает и без него).

## Как это устроено

1. Доска (768 бит) подаётся током на зрительные нейроны, мозг считается 100 шагов (50 мс «жизни»).
2. Спайки 2048 нейронов по всему мозгу -> обученный линейный слой -> оценка 4096 ходов -> лучший легальный.
3. Совпадение с ходом Stockfish ~42%.

Код: `flybrain/` (мозг и сервер), `viewer/` (3D-сайт), `scripts/` (обучение, не нужно для игры).
